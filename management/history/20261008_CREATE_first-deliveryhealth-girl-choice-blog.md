# 初めてのデリヘル向け女の子選びブログの作成と公開

- Type: CREATE
- Start Date: 2026-10-08

## 目的

Googleドキュメント原本を基に、初めてデリヘルを利用する人向けの女の子選びブログを作成し、確認用URLで本番閲覧できる状態にする。

## 対象範囲

対象ブログの公開PHP、本文HTML、専用データセット、共通データセット登録、専用CSS、原本画像3点、作成元Text、必要な履歴記録、および対象ファイルの本番公開確認。

ブログ一覧、トップページのブログ一覧、サイトマップから対象ページへのリンク追加は対象外とする。

## 完了条件

- 原本本文、目次、画像3点を反映した対象ページが作成されている。
- 既存CSSを基礎に、PC・スマートフォンで読みやすい洗練されたデザインになっている。
- title、description、canonical、OGP、見出し、画像alt、Article・BreadcrumbList・FAQPageの構造化データが本文と一致している。
- 一覧・トップページ・サイトマップに対象ページへのリンクを追加していない。
- 本番URLがHTTP 200で表示され、主要本文・画像・レスポンシブ表示を確認できている。

## 初期情報

- 原本はGoogleドキュメント `BLOG` のタブ `はじめてのデリヘル！女の子の選び方をブログ担当まいまいが本音で解説`。
- 原本タブには本文と画像3点がある。
- ユーザーは、SEOを意識した作成、既存CSSの優先利用、目次作成、原本画像の取得とサイズ調整、alt設定、一覧等からリンクせずURL単体での報告を指示した。
