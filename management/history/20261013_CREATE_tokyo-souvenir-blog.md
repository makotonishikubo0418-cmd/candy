# Candy東京土産ブログの作成と公開

- Type: CREATE
- Start Date: 2026-10-13

## 目的

Googleドキュメント原本を基に、店長の東京土産「東京ばな奈」と「東京ばな奈ぶにゃんこ」を紹介するCandyスタッフブログを作成し、本番URLで閲覧できる状態にする。

## 対象範囲

対象ブログの公開PHP、本文HTML、専用データセット、共通データセット登録、専用CSS、原本画像3点、作成元Text、ブログ一覧、トップページ最新15件、サイトマップ、生成管理書、履歴記録、および対象ファイルのGitHub・本番公開確認。

共通生成器の仕様変更、既存ブログ本文の変更、データベース操作は対象外とする。

## 完了条件

- 原本本文、4項目の目次、3点の原本画像を反映した対象ページが作成されている。
- PC・スマートフォンで階層、余白、画像説明、CTAが読みやすく表示されている。
- title、description、canonical、OGP、見出し、画像alt、Article・BreadcrumbListの構造化データが本文と一致している。
- ブログ一覧、トップページ最新15件、サイトマップ、生成管理書が新規ページと整合している。
- 対象変更だけをGitHub mainへPushし、Actions成功後に本番URLのHTTP・本文・画像・PC/SP表示を確認できている。

## 初期情報

- 原本はGoogleドキュメント BLOG のタブ「Candyに東京土産がやってきた🍌」。
- 原本タブには本文とJPEG画像3点がある。
- 原本には店長おすすめの女の子、お客様の声、FAQは存在しない。
- 現行の共通ブログ生成器はこれらの項目を必須とするため、原本にない内容を補わず、現行公開ページの構造を基礎に手動構成する。
