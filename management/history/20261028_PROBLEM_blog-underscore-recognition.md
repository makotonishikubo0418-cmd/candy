# アンダースコアを含むブログ名の認識漏れ修正

- Type: PROBLEM
- Start Date: 2026-10-28

## 目的

`candy_dominant_girls` のようにアンダースコアを含む既存ブログを、自動同期・検証・管理台帳で正しく認識する。

## 対象範囲

- `management/scripts/candy_page_common.py` のブログ一覧・トップページ同期、canonical、関連記事URLの読み取り。
- `management/scripts/candy_site_state.py` のページ分類と原稿canonicalの読み取り。
- 既存の回帰テスト、生成管理台帳、本件履歴。

## 完了条件

- アンダースコアを含む記事を欠落なく認識し、既存のハイフン形式も維持する。
- 一覧同期の欠落検出、重複検出、最新15件、繰り返し実行を検証する。
- 実在ブログ13件を台帳に分類し、生成管理書の内容が実ファイルと一致する。

## 初期情報

- ユーザーがブログ一覧に対象記事を追加した後、管理処理の認識漏れについて説明を求め、修正を明示した。
- 作業開始時の既存変更は `HP/source/blog.html` の一覧リンク1件追加のみ。この変更はユーザーの作業として保持する。
- 正規表現が英小文字・数字・ハイフンのみを対象とし、アンダースコアを含む記事を一覧・分類から除外していた。
