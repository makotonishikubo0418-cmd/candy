# 女性プロフィールのボタン配置とSP花柄余白の改修

- Type: MODIFY
- Start Date: 2026-09-20

## 目的

女性プロフィールの口コミ・マイページボタンの間隔を確保し、SPの花柄背景の余白を半分にする。

## 対象範囲

`HP/css/girls.css` のプロフィール用CSS、および `HP/source/girls.html` のCSSキャッシュ識別子。共通テンプレートを使う女性プロフィール全体を対象とする。Git公開・本番反映は含めない。

## 完了条件

- PC（769px以上）はボタンを横並びにし、間隔を15pxにする。
- SP（768px以下）はボタンを縦2段にし、間隔を15pxにする。
- SPの花柄部分の上下左右の余白を40pxから20pxにし、白枠内側およびPCの余白を維持する。
- 登録・解除の両表示と境界幅をローカルブラウザで確認し、文字切れと非表示ボタンによる余分な空白がないことを確認する。
- 重複・不要なボタンCSSを整理し、変更内容に対応するキャッシュ識別子を使用する。

## 初期情報

ユーザーが添付画像を示し、上記2点の改修を依頼した。実コード調査と計画の確認後、HPのみをGitHub `main` の `bc5a3f9d28f30258966dd6bf75b9f311b61b731a` と同期した状態で改修実行の指示を受けた。従来のボタン配置は `table` / `table-cell` で、SPの花柄余白は40pxだった。
