# 残りホテル15ページの作成と本番公開

- Type: CREATE
- Start Date: 2026-10-10

## 目的

作成可能として残っているホテル15ページをすべて生成し、GitHubおよび本番へ公開して、作成可能残数を0にする。

## 対象範囲

対象15ホテルのページ固有ファイル、共有登録ファイル、生成管理資料、GitHub Actions、本番ページ・画像・ホテル一覧・トップページ・サイトマップの検証。DB操作、画像の新規作成・置換、PC・モバイル画面確認、公開ツール自体の修正は含めない。

## 完了条件

15ホテルを独立したページCommitとして順番にGitHubへPushし、各Actionsが成功する。本番ページのHTTP、主要構造、画像、ホテル一覧、トップページ、サイトマップを確認し、公開URLを報告できる状態にする。入力監査上の作成可能残数が0であることを確認する。

## 初期情報

ユーザーから、残り15ホテルページをすべて作成し、アップロード後にURLを報告するよう明示的に指示された。
