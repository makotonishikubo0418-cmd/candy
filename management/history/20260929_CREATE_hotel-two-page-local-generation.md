# コンフォートイン鹿児島谷山・ホテル サントリーニのローカルページ作成

- Type: CREATE
- Start Date: 2026-09-29

## 目的

現行ホテルページ作成スクリプトを使用し、コンフォートイン鹿児島谷山とホテル サントリーニの2ページをローカルに作成して検査する。

## 対象範囲

対象2原稿、採用元画像4枚の初回ローカル設置、各ページの固有3ファイル、`dataset_base.php`、ホテル一覧、トップページのホテル欄、サイトマップ、生成管理資料。Git操作、GitHub公開、本番公開、DB操作は含めない。

## 完了条件

両原稿が現行形式として有効であり、画像が同名ハッシュ一致で `INSTALLED_LOCAL` となる。各ページの対象ゲート、生成、PHP構文検査、専用検査と、生成管理資料の全体整合性検査が合格する。

## 初期情報

ユーザーはホテルページを2ページ作成するよう指示し、HP閲覧者に対する店舗紹介を含む既定のホテルページ構成で実行することを確認した。対象は入力ファイル名順のコンフォートイン鹿児島谷山とホテル サントリーニ。
