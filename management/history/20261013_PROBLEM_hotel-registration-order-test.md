# ホテル掲載順テストの期待値修正

- Type: PROBLEM
- Start Date: 2026-10-13

## 目的

既存ホテルを再生成する回帰テストが「アトリエが必ず一覧末尾へ移る」と判定して失敗する問題を、正規の登録順・トップ表示仕様に沿って修正する。

## 対象範囲

ホテル登録順とトップ表示仕様の確認、`management/scripts/test_candy_tooling_recovery.py` の該当期待値と関連ケース、検証と履歴記録。ホテル生成処理・HP・原稿・正規仕様の変更、Git状態変更、DB操作、本番公開は含めない。先行する谷山港修正を保持する。

## 完了条件

正規仕様を根拠として既存再生成と新規登録を区別する期待値に修正し、トップ表示が登録順末尾15件と一致することを検査する。該当する失敗を解消し、同じ回帰テスト群全体が成功すること。

## 初期情報

[谷山港タイトル修正の検証](20261013_PROBLEM_taniyamakou-title-contamination.md)で、ホテル掲載順の既存テストが失敗し、変更前のコードでも同じ失敗を再現した。ユーザーは「そのホテル掲載順のテストも、正しい仕様を確認したうえで修正してください」と指示した。[最新15件制御の改修](20261008_MODIFY_hotel-top-latest-fifteen.md)は完了済みであり、本案件はその仕様を変更せずテストの固定期待値を修正する。
