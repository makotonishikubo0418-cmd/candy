# main全体Git同期判定の明確化

- Type: MODIFY
- Start Date: 2026-10-11

## 目的

`main`の同期確認でコミットSHAだけを判定せず、リポジトリ全体の未コミット・未追跡差分を含めた一貫した同期判定を行えるよう、Git管理書の正式ルールを明確化する。

## 対象範囲

`management/GIT_MANAGEMENT.md`の同期確認範囲、判定条件、確認手順、報告内容、および本変更に必要な履歴記録。

Git操作、GitHub公開、他の管理書の仕様変更、既存の未コミット差分の内容変更は対象外とする。

## 完了条件

- ブランチ名だけが指定された同期確認は、リポジトリルート全体を対象とすることが明記されている。
- コミット同期、作業ツリー同期、ブランチ全体同期の判定条件が分離されている。
- 変更済み、ステージ済み、未マージ、未追跡の差分が1件でもあれば、`main`全体を同期済みと報告しない規則が明記されている。
- 非クリーン時の件数、分類、全パスの報告要件が明記されている。
- 管理書と履歴の構成、参照、差分を検証し、既存の別案件差分を変更していない。

## 初期情報

- 2026-10-11の`main`同期確認で、ローカルとGitHubのコミットSHA一致だけを根拠に同期済みと報告し、`management/`配下の未コミット差分を全体判定から除外した。
- ユーザーは、`main`内部の全内容を同期確認対象として明確化するよう指示した。
