# URL・タイトル指定のブログテンプレート作成環境

- Type: CREATE
- Start Date: 2026-10-28

## 目的

URLとタイトルだけの依頼から、ユーザーが後で記事HTMLを作成してアップロードできるブログ一式を準備する環境を設ける。

## 対象範囲

management/template配下のコード管理書、作成・検証コマンド、回帰テスト、INDEX・ブログ関連管理書・履歴。例示された既存記事の作り直し、Git状態変更、DB操作、本番公開は対象外。

## 完了条件

- HTML・PHPの実コードを管理書に保存し、URL・タイトルから利用できる。
- 公開PHP、source HTML、dataset、共通登録、ブログ一覧、TOP最新15件、必要なJSON-LD、サイトマップを一式で準備できる。
- 本文差し替え方法、完成前後の区別、既存変更の保護を定義する。
- 正常生成、上書き防止、不整合検出、復元、構文を検証し、関連管理書から到達できる。

## 初期情報

ユーザーはmanagement/templateへのコード管理書設置とINDEX等の反映を相談し、HTML・関連PHP・TOPとブログ一覧・必要なJSON・サイトマップを含む環境の作成を明示した。記事本文HTMLはユーザーが後から作成する。本文原稿から完成ページを作る従来経路、既存スタッフブログのデザインテンプレートとは入力条件と完了条件が異なる。
