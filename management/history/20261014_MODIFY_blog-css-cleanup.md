# ブログ旧専用CSS削除と作成禁止ルールの整備

- Type: MODIFY
- Start Date: 2026-10-14

## 目的

ブログ独自の装飾をblog.cssへ集約し、旧専用CSSの削除と再作成禁止を徹底する。

## 対象範囲

HP/cssの旧ブログ専用CSS4件、blog.cssの編集案内、同CSSを参照する記事HTML4件と正式テンプレート、ブログ仕様・作成手順、生成台帳および履歴。

## 完了条件

- 旧専用CSS4件が削除され、実装からの参照がない。
- ブログ独自CSSの配置と記事別CSS作成禁止が正式管理書に明記される。
- 共通CSSと記事本文を維持し、参照先と更新キーが一致する。
- 生成台帳を更新し、検証結果と対象外の問題を区別して記録する。

## 初期情報

ユーザーはブログ独自のものをblog.css、サイト共通のものを既存共通CSSで管理し、HTMLとテンプレートを対応させた後に旧専用CSSを削除する方針を提示した。確認で旧4件の残存と作成手順の矛盾を報告し、ユーザーが「上記修正を実行してください」と承認した。前の共通CSS統合案件では旧CSS削除が対象外だったため、削除と禁止ルール整備を独立案件とする。

開始時に正式テンプレート更新の未コミット変更と、別作業によるcandy_dominant_girlsの記事本文変更があった。これらを保持する。
