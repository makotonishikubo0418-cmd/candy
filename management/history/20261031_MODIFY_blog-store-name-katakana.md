# ブログの表示用店舗名をカタカナへ統一

- Type: MODIFY
- Start Date: 2026-10-31

## 目的

既存ブログの表示用店舗名「Candy」を「キャンディ」に統一し、記事・SEO情報・一覧表示・現行原稿の整合性を保つ。

## 対象範囲

調査済み12記事のHTML、ブログ一覧とTOPの対象タイトル、管理台帳に登録された現行原稿6ファイル、関連する生成管理情報と本案件の履歴。記事内のalt属性を含む。英語デザイン表記、共通ブランド表記、URL、画像、CSS、プログラム識別子、過去の履歴・バックアップは変更対象外。
