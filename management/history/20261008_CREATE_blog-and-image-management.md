# ブログ継続作成・画像共通管理の整備

- Type: CREATE
- Start Date: 2026-10-08

## 目的

2件目以降のスタッフブログを同じ品質と手順で作成できる管理経路を設け、画像のalt、参照、遅延読込、再利用、実表示確認を共通管理する。トップページのスタッフブログ欄は最新15件以下に保つ。

## 対象範囲

ブログ作成手順、画像共通管理書、管理書INDEX、ブログ正規仕様、共通ページ生成規則、ブログ一覧とトップページの登録処理、トップページのスタッフブログ欄、回帰テスト、履歴。Git操作、GitHub Actions、本番公開、DB操作は含めない。

## 完了条件

ブログ作成と画像管理の責任範囲が重複なく管理書へ定義され、INDEXから到達できる。ブログ一覧を正規登録順としてトップページが末尾15件以下へ自動同期され、現在の最新記事を含む一覧とトップページのURL、表示名、順序が一致する。画像不表示を防ぐ現行遅延読込処理の条件と実DOM検証が明文化され、回帰テストが合格する。

## 初期情報
