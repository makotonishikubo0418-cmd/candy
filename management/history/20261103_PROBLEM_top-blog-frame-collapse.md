# TOPスタッフブログ枠の表示崩れと再発防止

- Type: PROBLEM
- Start Date: 2026-11-03

## 目的

TOP「スタッフブログ」の白い枠が記事を囲わず表示が崩れる問題を修復し、`synchronize_blog_top_index()` による再発を止める。検証と回帰テストで同じ壊れ方を検出できるようにする。

## 対象範囲

- `HP/source/index.html` のスタッフブログ枠構造
- `management/scripts/candy_page_common.py` のTOP同期と整合検査
- `management/scripts/test_candy_blog_template.py` の再発防止テスト
- 関連する生成管理書の同期と本案件履歴

GitHub保存・本番公開は、別途の明示許可と公開後実表示確認があるまで含めない。

## 完了条件

- 15件の記事が既存の白い枠内にあり、一覧ボタンは枠外にある。
- 一覧末尾15件とタイトル・URL・順序が一致する。
- 同期処理が枠内だけを置換し、不正構造では書込前に停止する。
- 構造検査と回帰テストが通る。
- ローカル修正結果が履歴に記録されている。本番復旧は公開後実表示確認まで完了としない。

## 初期情報

- 閉じタグが「BLOG INFO」直後にあり、記事15件が枠外へ出ていた。
- 過去のテンプレ作成でも閉じタグ移動が手動で戻されていたが、共通生成処理自体は未修正だった。
- ユーザーはローカル修復・生成修正・検証・テストを指示し、ローカルと本番を区別するよう求めた。
