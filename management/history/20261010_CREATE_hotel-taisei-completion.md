# ホテルタイセイページの完成と本番公開

- Type: CREATE
- Start Date: 2026-10-10

## 目的

共有登録だけが存在してページ本体が未作成だったホテルタイセイを完成させ、ホテルページ全体の未完成状態を解消する。

## 対象範囲

ホテルタイセイのページ固有ファイル、共有登録ファイル、生成管理資料、GitHub Actions、本番ページ・画像・ホテル一覧・トップページ・サイトマップの検証。DB操作、画像の新規作成・置換、PC・モバイル画面確認は含めない。

## 完了条件

ホテルタイセイのページをGitHubおよび本番へ公開し、Actions成功、本番HTTP 200、画像・一覧・トップページ・サイトマップの整合を確認する。ホテル入力71件について共有登録数とページファイル数が一致する状態にする。

## 初期情報

ホテルタイセイは元Textと画像2枚が存在し、共有ファイルとサイトマップに登録済みだったが、ページ本体、source HTML、専用データセットが存在せず、本番URLはHTTP 404だった。
