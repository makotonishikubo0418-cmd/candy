# Candy本番を正本とするローカルHPの同期

- Type: OPERATION
- Start Date: 2026-11-13

## 目的

サーバーのCandyフォルダから現在のファイルを取得し、ローカルHPをサーバーと一致させる。

## 対象範囲

- 取得元: `firststar.kir.jp` の `/firststar/public_html/group/candy` 全階層。
- 反映先: `C:\Codex\FSG\Candy\HP`。
- 既存ローカルHPの検証済み退避、現在の本番内容の取得、取得結果の検証、ローカルの追加・置換・余剰ファイル退避、最終比較。
- サーバーへの書込み、DB操作、Gitのstage・commit・push、GA設定変更は含まない。

## 完了条件

本番の現在のファイルを取得し、ローカルHPの相対パス・ファイル種別・通常ファイルのSHA-256が取得元と一致することを確認する。上書き・退避対象のローカル内容は復元可能な検証済みコピーとして保持する。

## 初期情報

- ユーザーの明示指示は「サーバーより現在DLして、ローカルをサーバーと同じにしろ」。
- 直前の比較では本番1,748ファイル、ローカル1,757ファイル、実質内容差15件、改行差413件、本番のみ12件、ローカルのみ21件だった。今回の取得前に本番の現在値を再確認する。
- 直前の比較とは完了条件が異なり、今回は本番を正本にローカルHPへ反映する作業である。
- Candy専用READ-ONLY接続は直下一覧までであり、全階層取得に利用する接続の用途確認が必要。
