# DB・サーバー・Gitの確認可否調査

- Type: INVESTIGATE
- Start Date: 2026-10-11

## 目的

現在の作業環境からCandyのDB・本番サーバー・Gitを確認できるか判定する。

## 対象範囲

DB専用READ-ONLY経路の前提条件と許可後の接続確認、本番サーバーのREAD-ONLY接続確認、Candyリポジトリのローカル状態とGitHubの参照確認。

## 完了条件

各対象について実証できた確認範囲、確認できない範囲と理由を区別し、ユーザーへ報告する。DBの実接続確認を行わない場合は、その範囲をユーザーと確定する。

## 初期情報

ユーザーから「DB サーバー Git 確認できるか確認してください。」と指示された。Gitの状態変更およびDB操作の許可条件は、ルートAGENTS.mdに従う。
